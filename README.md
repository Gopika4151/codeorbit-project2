# 🎮 Tic-Tac-Toe with Artificial Intelligence

## 📌 Project Overview
Tic-Tac-Toe with AI is an interactive web-based game developed using HTML, CSS, and JavaScript.

The game allows a human player to compete against a computer opponent that uses the Minimax algorithm to select its moves.

This project was developed as part of the CodeOrbit Tech Artificial Intelligence Internship.

## 🎯 Objective
To develop a Tic-Tac-Toe game with an intelligent AI opponent that can detect winning, losing, and draw conditions.

## ⚙️ How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Select any empty cell to make your move.
5. The computer automatically makes its move.
6. Continue playing until the game ends.

## 🧠 Working Principle
1. The player selects a cell and places X.
2. The game checks the winning conditions.
3. The Minimax algorithm evaluates possible computer moves.
4. The computer selects the best available move and places O.
5. The game checks for a winner or draw.
6. The scores are updated automatically.

## 🤖 AI Algorithm – Minimax
The Minimax algorithm is a decision-making algorithm used in two-player games.

- Maximizing Player: Computer (O)
- Minimizing Player: Human (X)
- Winning Score: +10
- Losing Score: -10
- Draw Score: 0

The algorithm evaluates possible game states and selects the best move for the computer.
